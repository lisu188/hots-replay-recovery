# Dragon Shire opening gate order

The GateOrder map derives the order of the two opening blocker groups from the positions of their current unit handles. It removes the ordinary group first, then the diagonal group. Within each group it selects ascending Y, then ascending X. The Dragon Shire placements are unique within each group. The map embeds no replay tags, replay ordering, handle table or fixed gate time.

The pinned KeepCatapults map calls the GameLib initializer from `InitLibs`. GateOrder substitutes a copy of that initializer at the same call site. It uses the original completion flag and calls the same variable initializers. In the stock sequence of 176 trigger initialization calls, entry 62 creates the GatesOpen trigger in its original global and registers the original timer. The callback name passed to that one creation changes. Both group queries, their filters, the arena guard, the original wait, all other callback actions and their relative positions are preserved. The sorter operates on the private group returned by each query. It explicitly drops the selected handle from that group before each `UnitRemove`.

Two independently built map archives matched at 2,149,576 bytes, SHA-256 `bda7aafd1d63c77b3b4d29ff2afee96da09a3104b54b4a1d625bb299607d9008`. Both archive readers agreed on every member. All 69 content members besides `MapScript.galaxy` were byte-identical to KeepCatapults.

The verifier reads the emitted Galaxy sorter back from the archive and executes that function in a C harness with mock native calls. It compared 256 independent orderings of each of the 30 ordinary and 24 diagonal placements plus empty, singleton and signed-coordinate groups. The resulting TEN_GREYMANE tracker projection reproduced the 1,836-byte reference for 54 deaths at loop 610. The historical spatial rule agreed with 216 of 216 removal positions in four build-41810 recordings. In the 15 unmodified build-98348 controls it agreed with 30 of 810 positions.

Use `build_gate_order_map.py --help` with the pinned KeepCatapults map, extracted GameLib, spatial receipt and an unused output path. Use `verify_gate_order_map.py --help` with that map, its parent, the extracted 98348 library inventory and a C compiler. The public builder and verifier contain no original map or replay data. The map is a separate offline prototype. Native Galaxy compilation, actual retirement order, first-wave tags, game playback and complete conversion remain unverified.
