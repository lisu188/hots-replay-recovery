# TEN's first two movement commands

Through loop 64, two TEN players each issued their first implicit point command with sequence 1. The second player sent point updates at loops 63 and 64 before their next command-manager record. Both updates have an absent sequence in the original 41810 wire. The independent projection retains the original user, loop and coordinates, translates the initial movement flags from `0x100108` to `0x80108`, includes the absent target vector, and supplies the preceding command's sequence for those two updates. The resulting four sparse 98348 game-event frames occupy 72 bytes.

This predictor applies only to the first qualifying command of a user and up to two following point updates. A reset, new issue, unit update or command-manager entry closes the interval. Each of the 24 genuine build-98348 recordings was scored from the beginning through loop 1,500. All 231 eligible initial issues and all 160 eligible updates matched their individual physical byte spans, including the event's original delta from the preceding game event. The predictor reads the preceding issue's sequence. Each update's own sequence is used only to check the prediction. The four projected TEN frames use the original positions and timing.
