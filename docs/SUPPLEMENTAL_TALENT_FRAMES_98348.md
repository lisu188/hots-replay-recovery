# Target indices witnessed across additional maps

Nine public 98348 replays, disjoint from the twelve Dragon Shire controls, supplied exact command-index witnesses for eleven more TEN_GREYMANE purchases. With both samples, two independent encoders agree on 22 isolated seven-byte frames for 19 distinct hero/talent choices. Each frame uses the source input’s numeric user slot and time since the immediately preceding game event. Eighteen other purchases have a direct target tree entry without a wire witness. Thirty have no direct entry. [Frame results](../observations/target-talent-frames-supplemental-98348.json) · [Witnesses by replay and map/mod checksum](../observations/supplemental-target-talent-witnesses-98348.json)

The extra controls cover eight map/mod pairs on the same data root. All 615 selections paired with exactly one purchase for the same player one loop later. Independently, the active-tier model erased the 105 scoped tracker names, reproduced every name and rebuilt all 4,764,649 tracker bytes across these controls. Running the single-replay check with `--witnesses` exposes each predicted name, loop, index, tier and column. The other fields and out-of-scope names come from the recording. The Sky Temple tracker contains the exact identifier `BrightwingArcaneFlareHush!`. The auditor now accepts a single trailing exclamation point in a purchase identifier and retains it in the output.
