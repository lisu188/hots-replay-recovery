The current target catalog gives a separate, mechanically relevant constraint. Impale issues one initial damage search and 7 periodic searches with a 0.125-second period. Extended Spikes changes the 7 to 9, yielding 8 or 10 search requests. Each routes through a 0.25-second delayed effect to the search rectangle. The ability's input range is 500. The second persistent effect also runs gameplay logic. Bed of Barbs changes its delayed effect's chance from 0 to 1. Each qualifying position can then request 28 periodic area searches, including a target switch for structures and slow/damage for eligible ordinary targets. Two extra positions can therefore request 56 additional area queries. TEN's tracker recorded Bed of Barbs for this player at loop 4583. These target declarations support retaining both period-count changes in ExtendedSpikesRange. They leave the 41810 period spacing, contact radius and discovery of surviving targets unresolved.
