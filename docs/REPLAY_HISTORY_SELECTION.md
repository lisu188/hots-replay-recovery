# How a fresh 98348 replay request selects setup history

Opening a replay from the file-request branch at RVA `FB870B` supplies mode 2 and state class 0. The archive path goes to manager method `+1F8`. The optional history path used by the setup predicate starts empty and this file request skips its setter. A fresh manager with that initial path at Apply selects the clean setup branch. This narrows the offline prediction for TEN's target conversion and for each of the 24 independent native controls.
