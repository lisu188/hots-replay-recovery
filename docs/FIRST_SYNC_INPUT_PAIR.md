To rebuild the game prefix, run `python first_sync_game.py TEN TARGET_SELECTIONS --native-case SHA256 REPLAY --private-output NEW.bin`, repeating the native-case option for the controls. The selection input is the separately generated four-frame target selection projection. Then run `python verify_first_sync_inputs.py TEN TRACKER_PREFIX GAME_PREFIX`. The verifier checks both target byte extents, source input order, ownership, movement data and the original sync marker. [Paired result](../observations/first-sync-input-pair.json)
