## CI issues found and repaired

1. The unmodified upstream package imports `imp`, which is absent from Python 3.13. The independent validation job now uses Python 3.11.
2. Default piped shell commands allowed `tee` to hide an earlier test failure. The workflow now uses Bash with pipefail; a failed check prevents checkpoint publication.
3. The original `(listfile)` has a valid CRC32 but an all-zero MD5 slot in `(attributes)`. It is preserved rather than mistaken for new corruption. The verifier checks its CRC32 and its independently known content MD5 `8b539c554452a290100542cc97a05439`, and records the inherited missing MD5 slot separately.
4. PyPI mpyq 0.2.5 has no `MPQArchive.close()` method. Cleanup now closes its underlying file directly, without masking the original validation failure.
5. Artifact restoration now validates contiguous Base64 parts, strict encoding and SHA-256 before atomically replacing the output. Invalid data must not overwrite an existing replay.
