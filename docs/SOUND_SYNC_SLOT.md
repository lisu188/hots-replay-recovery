# Sound handles in sync slot 42

The full build-98348 producer hashes the number of registered Galaxy sound objects followed by their complete 32-bit handles in registration order. Each word is little-endian. Calling `sound_list_crc(handles)` with the complete list yields slot 42. A zero-length list contributes a four-byte zero count, giving `0x2144df1c`. The original PE starts with a zero count and null pointer. Sampling a fresh fast-mode-4 entry with world bit 6 clear yields `0` for this slot. [History selection](SYNC_HISTORY_CADENCE.md)

The full builder at `0x970c88` seeds the accumulator, calls `0xac5d80`, complements the result and stores it at entry offset `0xb0`. The producer hashes the count at `0x2f719f8`, then passes the count and the vector at `0x2f71a08` to `0x2d71a0`. That helper reads one DWORD per iteration. The native CRC tables agree with zlib on empty, single-word, multiword and reordered inputs. Swapping two distinct example handles changes the resulting CRC.

After the shared allocator returns, the ordinary sound creation path at `0x20d62e7` invokes virtual slot `+0x50`. Its class-15 table at `0x26b4e98` points to `0xac6280`, which appends the DWORD at `object+8`. Retirement removes a matching word and compacts the remainder in order. The sound-update pass also tests registry class 15. `SoundLink` returns a separate class-16 object that does not take this sound constructor path. [Opening allocation evidence](ANNOUNCER_ALLOCATION.md)

The 98348 GameLib ordinary startup sequence plays `Gen_HeroRespawn_GameStart` for all players, waits the hero spawn delay, then starts hero spawning. The first four TEN hero births are at loops 50, 50, 58 and 58. The first offset report is at 68. None of the 24 target or five historical controls reported any offset through loop 64. Twenty-three target recordings and all five historical recordings already had at least one player-controlled unit birth with a type beginning with `Hero` before 64. All 29 recorded a folded type-2 first checksum. A report-free interval therefore supplies neither the handle of the pre-spawn sound nor its lifetime. The TEN list and selected slot value at loop 64 remain unresolved. The empty-list CRC is a reproducible initialization value.

Another 28 distinct build-98348 recordings contained 8,976 synchronization records. Each re-encoded to the original bytes, and every record was folded type 2. Together with the earlier 24 controls, 52 current-build recordings supply no explicit history vector for the first marker.
