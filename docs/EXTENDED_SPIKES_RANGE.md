# Anub'arak's opening Extended Spikes purchase

TEN player 2 chose Anub'arak's selector 0 at game ordinal 491, loop 102. The 41810 tracker awarded `AnubarakMasteryExtendedSpikesImpale` at ordinal 244, loop 103. The 41810 catalog puts Extended Spikes first in the level-one tree and describes a 25% increase in Impale's maximum range. Blizzard documented the addition of 25% bonus damage on May 17, 2016 and the talent's removal on March 14, 2017. [41810 hero catalog](https://github.com/nydus/heroesjson/blob/bd1723601cc1a7c05e9417bf76b7fe10297e7ba8/heroes.json) · [May 2016 patch](https://news.blizzard.com/en-us/article/20120032/heroes-of-the-storm-patch-notes-may-17-2016) · [March 2017 patch](https://news.blizzard.com/en-us/article/20581822/heroes-of-the-storm-patch-notes-march-14-2017)

ExtendedSpikesRange is a separate 2,198,317-byte Dragon Shire package derived from MercCapture. Its SHA-256 is `e7ce5d12d5a93840a333a6e27b3f15d9cab9917be2e88d0040f19d638e4f9bbf`. Two builds matched byte for byte. Each archive reader found 71 content members. The new HeroData.xml replaces the talent link in Anub'arak's first tree row, preserving tier 1 and column 1. TalentData.xml removes the seven trailing Impale damage modifiers from the dormant current talent. Both archives have identical bytes for the other 69 content members.

The seven removed records each added 0.25 through a separate flat modification. The target GameLib reads the active count and applies each flat numeric modifier with a per-player catalog write. Supplying zero for those seven values would still request seven writes. The candidate marks indices 12 through 6 removed, in descending order. The installed GreymaneWorgen declaration supplies an example of nested `Modifications index="1" removed="1"` under a different catalog field. The six retained target records extend both effect paths by two periods, raise the guide by 3, substitute two sounds, and move a sound offset. Exact historical geometry, sound behavior, target catalog loading, and resulting synchronized state remain unverified. The current effect sample centers end at −10.5 before adding the two periods and −13.5 afterwards, so those centers alone do not establish historical 25% world-space range.

The verifier scanned all 29 pinned Dragon Shire recordings. TEN was the only qualifying 41810 first selection of selector 0 for Anub'arak. One 98348 recording contained the corresponding stock choice, which awarded Nerubian Armor at loop 347. GameLib derives the purchase string from the selected hero-tree column. Using the candidate tree and pinned startup identity/level, the translator derives the historical name and matches the two TEN frames at their original physical deltas. As separate target-grammar fragments, the selection takes 8 bytes and the award takes 114 bytes. No recording in these controls uses the new package.

The opt-in sparse game stream contains 17,708 inputs, 142,559 bytes, SHA-256 `0d412eb98d802c9266f851581020f7a54c708654ed18f89e5cb0c5f5b6338d53`. It carries the new choice and 17,707 existing MercCapture projections. After the choice it retains camera, untargeted pings, recorded chat and departures, and previously verified first selectors for the two unaffected heroes under their original award-state conditions. It withholds 3,878 previous projections, including later commands, tag/ownership/trajectory cases, unverified subsequent talent awards and soundtrack schedules. Counts by each parent producer and the affected user's counts appear in the receipt. The first gap remains game ordinal 33, loop 68, and 86,549 source inputs remain unrepresented.

Use new output paths with the following commands. The standalone verifier needs the pinned private 29-replay manifest. Its GameLib and Anub'arak XML come from build 98348, and its startup prefix is the original signed prefix ending before the new award. The historical catalog is the 41810 export. The optional join takes the existing 21,585-row MercCapture projection, its separately published receipt and the new translator receipt.
